# PokéRogue · sito di presentazione

Pagina di presentazione di PokéRogue, un roguelite d'azione amatoriale e non commerciale con i Pokémon di Kanto, Johto, Hoenn e Sinnoh. È una pagina statica (`index.html`, con `img/` e `fonts/`) pubblicata con GitHub Pages.

Il gioco non viene distribuito: questo repository contiene solo la pagina e le immagini del gioco usate per presentarlo.
